# Альфа-Бизнес — прототип главной

HTML/CSS-прототип главной страницы Альфа-Бизнеса с концептом блока «Дела» и онбординга.

## Как открыть

Откройте `index.html` через любой локальный сервер, например:

```bash
python3 -m http.server 5173
```

и перейдите на http://localhost:5173/.

## Состояния

Переключатель внизу экрана (или клавиши Q / W / E):

- **Первый вход** — новый клиент: пустая лента, карусель заданий;
- **В работе** — дела во всех статусах, онбординг пройден частично;
- **Прошёл онбординг** — все задания выполнены, баллы можно потратить.

Также работают параметры URL: `?v=old|new&s=novice|expert|done`.
